# Paradox Cli

A command-line assistant for coding, extensible workflows, and financial research.

## What you can do

- Explore a project, understand code, and make changes with file and terminal tools.
- Control tool access with permissions, approvals, and sandbox options.
- Save and resume conversations, manage context, and use project memory.
- Extend your workflow with skills, custom commands, hooks, and connected tools.
- Choose a model provider and use your own API key, including Kether and compatible services.
- Analyze financial data with local indicators, risk summaries, and research backtests. These features do not place live trades.

Some features need a separately configured provider or service. Model use may incur charges from your chosen provider.

## Downloads

## Your keys and preferences

You configure your own provider credentials. Optional usage uploads are disabled by default and require explicit configuration.
